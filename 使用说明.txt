CleanC —— C 盘清理工具
======================================================================
【电脑的要求】

  * Windows 7 及以上。Win10 / Win11 自带 PowerShell 5.1，不用另装。
  * 管理员权限——程序会自己弹 UAC 提权，点“是”就行。
  * 清理目标写死的是 C 盘系统路径，所以对方要腾空间的是 C 盘才有意义。

【第一次打开可能被拦】

  1. SmartScreen
     这个 exe 没有数字签名，如果它是从微信 / QQ / 网盘下来的，Windows 会提示
     “Windows 已保护你的电脑”。
     → 点“更多信息” → “仍要运行”。

  2. 杀毒软件
     用 ps2exe 打包出来的 exe 经常被误报。卡巴斯基 / 360 / 腾讯电脑管家
     可能直接删掉或隔离。
     → 让对方先加白名单；发的时候用压缩包，能少一层传输途中的扫描。
       不要为了这个去关杀毒软件。

  3. 微信 / QQ 部分版本不收 .exe
     → 压成 .zip 再发。

【怎么用】

  1. 双击 C盘清理工具.exe，UAC 点“是”。
  2. 点“扫描”，等它跑完。列表按风险分三档：

         安全（绿色）—— 零风险，默认已勾选
         注意（黄色）—— 要你自己判断，默认不勾
         勿动（灰色）—— 根本不让勾，看“说明”列有原因

  3. 勾好要清的，点“清理选中项”；或者直接点“一键清理安全项”。
  4. 清理前会弹确认框说清楚要删什么。确认后按 C 盘剩余空间的实际变化
     统计结果——不是把文件大小加起来糊弄你。
  5. “导出 CSV”可以把扫描结果存下来，中文表头 Excel 直接能读。
  6. 工具栏最右边的“显示禁止删除项”可以控制灰色那档要不要露出来。

【它不会做什么】

  * 不会删任何你没勾的东西
  * 不碰 Windows\Installer、Defender 病毒库、正在用的程序数据
  * 不碰注册表，不卸载软件，不改系统设置

【日志】

  每次运行会在 exe 所在目录生成 / 追加 CleanC.log。
  如果 exe 放在只读位置（共享盘、写保护的 U 盘），日志会自动退到
  %TEMP%\CleanC.log。
